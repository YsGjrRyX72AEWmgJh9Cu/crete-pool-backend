# Domain Rules

Version 1.0

---

# Purpose

This document defines the universal rules that govern the Domain Model of the Hellenic American Pool History Platform.

Domain Rules preserve consistency, historical accuracy and domain integrity across the entire platform.

These rules apply to every Domain Entity unless explicitly overridden by a Domain Specification.

---

# Identity Rules

Every Domain Entity owns its Platform Identity.

Platform Identity is permanent.

External identifiers never replace Platform Identity.

Source references preserve provenance.

---

# Historical Rules

History is preserved, not recreated.

Historical information is corrected, not replaced.

Historical provenance must always be preserved.

Uncertainty is preserved rather than invented.

The platform preserves historical facts without interpretation.

---

# Domain Rules

Every Domain Entity must have a clear historical purpose.

Every Domain Entity must have a clear business purpose.

Relationships belong to the Domain, not to external systems.

External information is translated into the Domain Model.

The Domain Model owns the language of the platform.

---

# Documentation Rules

Specifications describe concepts before implementation.

Documentation should use preservation-oriented language whenever appropriate.

Every Specification must remain consistent with the Domain Model.

Every Specification must remain consistent with the Project Constitution.

---

# Review Checklist

Before introducing a new Domain Rule, verify that:

- The rule applies across the entire Domain.
- The rule is independent of implementation details.
- The rule supports historical preservation.
- The rule does not duplicate entity-specific rules.
- The rule is consistent with the Domain Model.
- The rule is consistent with the Project Constitution.

---

# Scope

Domain Rules define principles that apply across the entire Domain Model.

Entity-specific rules belong to their corresponding Domain Specifications.

Implementation-specific rules belong to the implementation.
